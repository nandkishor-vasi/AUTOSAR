# AUTOSAR HLD Architecture Intelligence & Impact Analysis Assistant

Academic Applied AI/ML capstone using synthetic automotive HLD documents.

## Core capabilities
- PDF ingestion and page provenance
- Local embeddings / fallback retrieval
- RAG question answering with citations
- Architecture entity extraction
- Relationship exploration
- Impact analysis
- Revision comparison
- Potential inconsistency detection
- Deterministic evaluation with ground truth

## Quick start
```bash
python -m venv .venv
# Windows PowerShell: .venv\Scripts\Activate.ps1
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
python scripts/run_all.py
python evaluation/run_evaluation.py
uvicorn app.main:app --reload
streamlit run frontend/streamlit_app.py
```

## Retrieval modes
The project prefers sentence-transformers + ChromaDB when installed. A deterministic TF-IDF fallback keeps the academic demo runnable if those packages/models are unavailable.

## Local LLM
Install Ollama separately and pull a small local model. Set `DEMO_MODE=false` and configure `LLM_MODEL` in `.env` when ready. The application still works in DEMO/FALLBACK mode without Ollama.

## Synthetic data
All PDFs under `data/documents/` are marked `SYNTHETIC DATA FOR ACADEMIC PROJECT`. They are not real OEM documents.

## Important
Evaluation numbers must be generated by `evaluation/run_evaluation.py`; no metrics are manually fabricated.
